# Interview Prep – Raghwendra Mishra

Private question banks for DevOps / Platform / Cloud interviews (1 to 7 years experience).

## Folders
- `questions/01-allianz-interview-prep.md` – Allianz GI prep: JD summary, tell-me-about-yourself, Unity Catalog, 115 Q&A.
- `questions/02-allianz-jd-questions-1-to-7-years.md` – 54 JD-based questions by level, with simple explanations.
- `questions/03-aks-databricks-100-questions.md` – 100 AKS, Kubernetes YAML, secrets, networking, and Databricks questions.
- `questions/04-resume-based-120-questions.md` – 120 questions tied to resume claims and the JD, plus 20 scenario questions.

## How to use
1. Read the question, answer out loud in 60–90 seconds.
2. Compare with the answer, then note what you missed.
3. Re-answer the weakest questions the next day.
